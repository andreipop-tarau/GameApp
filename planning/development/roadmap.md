# Optimized repath roadmap

ADR 0002 remains the approved product/architecture decision. This roadmap replaces the original 31-task repath sequence with three active milestones and one conditional expansion milestone. Tasks 001-015 remain foundation history; original repath Tasks 016-046 are superseded by the mapping in `backlog.md`.

## R1 — Two-game Troll Gauntlet vertical slice (current)

Six focused sessions deliver the minimal v2 runtime, slice-only visual/tell primitives, Stop the Machine, Hold It, deterministic Director/run policy, and Home-to-Gauntlet integration. Gate G1 measures comprehension, responsiveness, lifecycle safety, accessibility, replay, and device performance before more mechanics are built.

## R2 — Representative catalog proof

Add Don't Press It, Protect the Egg, and Wrong Way so the playable set covers tap, hold, drag, swipe, inactivity/deception, and a genuine modifier. Integrate the five-game catalog and run Gate G2. Do not implement the remaining catalog merely to satisfy a document.

## R3 — Local product compatibility

Only after G2 passes: migrate save v1 to additive v2, add mastery/personal best presentation, implement minimal accessibility/settings and interaction-led onboarding, then remove the unreachable legacy primary-session path. Cosmetics presentation and broad shell expansion remain deferred.

## R4 — Conditional content and mode expansion

After G2 evidence, retain this order unless measured issues require correction first:

1. Remaining catalog: Escape Button, Feed the Idiot, Keep Inside, Parking Disaster, Clean the Screen, then Boss: The App Is Broken.
2. Full-catalog balance/boss validation and removal of legacy pure modules only when save compatibility no longer needs their identifiers.
3. Flow Run foundation, Calm Run, then Rush Run.
4. Local cosmetics presentation, original production audio/assets, and release-quality cross-mode polish.

R4 items remain approved roadmap outcomes but receive detailed task prompts only when the preceding gate passes. This avoids planning APIs and asset systems before their real consumers exist.

## Deferred infrastructure

Cloud accounts/sync, daily competition, leaderboards, server currency/inventory, purchases, remote LiveOps, social, notifications, and online AI remain outside the active roadmap. They require separate evidence and authorization.
