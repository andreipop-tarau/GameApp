Storage and Media

Purpose

Manage user-generated and game assets.

Stored Content

-   Avatars
-   Shared images
-   Event assets
-   Remote configuration
-   Audio packs

Rules

-   Compression before upload.
-   CDN delivery.
-   Cache frequently used assets.

Acceptance Criteria

-   Fast downloads.
-   Secure uploads.
